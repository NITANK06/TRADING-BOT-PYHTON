# TRADING-BOT-PYHTON


A simplified Python trading bot for Binance Futures Testnet (USDT-M).
This application allows you to place Market and Limit orders (BUY/SELL) via the command line, with structured code, logging, and error handling.

** Features**

Place Market and Limit orders on Binance Futures Testnet

Supports both BUY and SELL sides

CLI input validation with argparse

Clear output of order request and response details

Structured code: separate API client and CLI layers

Logging of requests, responses, and errors to log files

Exception handling for invalid input, API errors, and network failures

** Requirements**

Python 3.8+

Dependencies:

python-binance
